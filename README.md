# LOL Broadcast HUD

리그 오브 레전드 대회용 OBS 밴픽, 인게임 HUD 및 결과 화면입니다. 웹 밴픽, BO5 하드 피어리스와 RoFS를 지원합니다.

## 최근 변경 사항 (2026-11-12)

- 롤 클라이언트 밴픽도 실제 경기의 양 팀 픽을 기록해 다음 밴픽에서 피어리스 목록을 표시합니다. 새 시리즈에서는 클라이언트 피어리스 기록을 초기화하세요.
- 컨트롤 패널에서 팀을 교체하면 팀명·선수명·로고·세트 승수가 함께 이동합니다. 웹 밴픽이 진행 중일 때는 교체가 제한됩니다.
- 인게임 양옆에 수동 입력한 선수명을 표시하고, 블루·레드 진영 색상은 고정합니다. 포탑 숫자는 골드 글자 크기 설정을 따릅니다.
- 룬 아이콘의 첫 변화를 이용한 라인 퀘스트 자동 표시를 시험 기능으로 추가했습니다. 완료 전부터 켜고, 롤 선수 패널이 보이는지와 인식 상태를 확인하세요. 이미 바뀐 아이콘은 수동으로 보정해야 합니다.
- 바론·전령 수치를 수동 입력해 결과에 저장하고, 결과창에서는 처치 횟수만큼 아이콘으로 표시합니다. 아이콘은 [게임 에셋을 사용하는 프로젝트](https://github.com/drewfoos/scoreboard-lol)에서 가져왔습니다.
- 결과창 게임 스탯의 우세 지표에 진영별 빛 효과를 표시합니다. KDA는 (킬+어시스트) / 최대(1, 데스)로 비교합니다.
- 롤 게임이 꺼져 있을 때 화면 OCR을 쉬게 하고 결과창 갱신의 중복 처리를 줄였습니다. 인식은 화면 배치와 가림 여부에 영향을 받으므로 실전 전 확인이 필요합니다.

## 변경 사항 (2026-11-11)

- 웹 밴픽을 켠 채로 픽 교환이 끝나면 인게임 데이터를 연동하고, 피어리스 픽·밴 기록을 유지합니다.
- 블루는 왼쪽과 파란색, 레드는 오른쪽과 빨간색으로 고정하며 진영이 바뀌면 팀과 세트 승수가 함께 이동합니다.
- 결과 저장 시 승리 팀의 해당 세트 승수를 결과 화면에 표시합니다. 실제 피어리스 세트 승수는 ‘경기 결과 저장 · 다음 세트’에서 확정됩니다.

- 밴픽 상단에 팀 로고, 팀명, 세트 점수를 대칭으로 배치하고 중앙 로고 아래 대회 이름 표시를 제거했습니다.
- 컨트롤 페이지에서 약칭, 팀 색상 및 팀명 아래 문구 입력을 제거하고, 밴픽·인게임·결과 화면에 팀명을 표시합니다.
- 결과 화면에서 SVG 로고를 지원하고, 현재 팀 설정을 저장된 결과에 연결합니다. 팀을 식별할 수 없으면 현재 진영을 기준으로 표시하므로 결과를 방송하기 전에 팀 구성을 확인하세요.
- RoFS로 진영을 교체해도 팀 로고와 세트 승수가 해당 팀을 따라갑니다. 경기 결과와 RoFS는 컨트롤 페이지에서 직접 입력합니다.
- 인게임 세트 승수 막대의 구분과 좌우 대칭을 개선했습니다.

## 버전 0.2.0 (2026-11-11)

- 결과 화면 색상을 차콜·청회색으로 조정하고 블루·레드 승리 표시를 구분했습니다.
- 결과 화면의 대회 이름, 라운드/매치와 게임 번호가 컨트롤 페이지 설정을 따릅니다. 저장된 경기 통계는 유지되며, 팀 표시에는 현재 팀 설정이 반영됩니다.
- 결과 화면의 KDA 글자 간격을 넓혔습니다.
- 컨트롤 페이지의 대회 로고를 인게임과 결과 화면에도 표시하고, 결과 화면의 팀 로고를 팀 이름에 맞게 갱신합니다.
- Cloudflare 도구가 없으면 외부 접속 시작 시 공식 다운로드 페이지와 설치 안내를 표시합니다.
- 인게임 HUD는 기존 색상을 유지합니다.

결과의 게임 번호를 바꾼 뒤에는 해당 경기의 통계를 다시 저장해야 결과 내용과 번호가 일치합니다.

## 주요 기능

- 40초 픽 교환 시간을 포함한 웹 밴픽과 OBS 관전 화면
- BO5 하드 피어리스: 이전 세트에서 픽한 챔피언을 제한하고 세트별 목록 표시
- RoFS: 운영자가 양 팀의 진영 및 선후픽 선택을 입력하며, 레드 선픽도 지원
- 인게임 점수판과 경기 결과 화면, 딜량·골드 그래프 이미지 인식

RoFS 선택과 세트 결과는 컨트롤 페이지에서 운영자가 입력합니다. 웹 밴픽은 롤 클라이언트에 픽을 자동 입력하지 않습니다.

## 웹 밴픽과 외부 접속

1. 컨트롤 페이지에서 일반 새 방 또는 BO5 피어리스 시리즈를 시작하고, 양 팀에 각각의 팀 전용 링크를 전달합니다. 링크 전체는 비밀로 유지하세요.
2. 양 팀이 준비하면 밴픽이 시작됩니다. 시간 초과 시 밴은 없음으로 처리하고, 픽은 선택 중인 챔피언이나 무작위 챔피언으로 확정합니다. 마지막 픽 이후 40초 동안 드래그로 자리를 바꿀 수 있습니다.
3. 웹 밴픽 결과는 롤 클라이언트에 자동 입력되지 않으므로 참가자들이 게임에서 직접 같은 챔피언을 선택해야 합니다. OBS에는 로컬 `/draft.html`을 사용하세요.
4. 피어리스는 이전 세트의 모든 픽을 제한합니다. 운영자는 매 세트 결과와 RoFS 진영·선후픽 선택을 입력하고 새 팀 링크를 전달합니다.

다른 지역의 참가자는 `127.0.0.1`을 사용할 수 없습니다. 외부 접속 시작 버튼으로 임시 HTTPS 주소를 생성하세요. Cloudflare Quick Tunnel은 재시작할 때 주소가 바뀌는 테스트용 서비스이므로 실전 전에 연결을 점검하고 새 주소와 팀 링크를 전달하세요. 서버 PC와 HUD 및 외부 연결이 켜져 있어야 합니다. 외부 링크는 웹 밴픽과 팀 정보가 보이므로 공개 게시하지 마세요.

## 결과 저장

경기 종료 후 컨트롤 페이지에서 승리 팀을 선택하고 ‘현재 경기 결과 저장’을 누른 다음 딜량 이미지 등을 올립니다. 바론·전령 수동 입력도 저장 시 결과에 반영됩니다. 결과 저장을 다시 누르면 기존 업로드 그래프 데이터가 초기화됩니다. 골드는 X 점수판 화면 인식, 용 스택은 수동 입력에 의존하며 실제 방송 전 연결과 인식 상태를 확인하세요.

## 실행

Windows 10/11 64비트와 Node.js 24가 필요합니다. 이 저장소에는 Node.js 실행 파일이 포함되지 않습니다.

```powershell
node server.js
```

실행 창을 유지하고 브라우저에서 `http://127.0.0.1:3197/control.html`을 여세요. OBS 브라우저 소스 주소는 `/draft.html`, `/ingame.html`, `/result.html`이며 1920×1080으로 설정합니다. 처음 챔피언 데이터를 불러올 때 인터넷 연결이 필요합니다.

외부 웹 밴픽을 사용하려면 컨트롤 화면에서 외부 접속 시작을 누르세요. 도구가 없으면 열리는 공식 다운로드 페이지에서 Windows 64비트 실행 파일을 받은 뒤, 이름을 `cloudflared.exe`로 바꾸고 `runtime/cloudflared.exe`에 넣습니다. 다시 외부 접속 시작을 누르면 연결할 수 있습니다. 팀 링크는 해당 팀에게만 전달하세요. 로컬 서버가 실행 중이어야 합니다.

`data/state.example.json`은 개인 경기 정보를 제거한 초기 설정입니다. 첫 실행 시 로컬 `data/state.json`이 생성되며 Git에서 제외됩니다. 실행 중 생성된 경기 정보와 팀 링크, 업로드 파일은 공개하지 마세요. 이미지 인식은 화면 배치와 해상도에 영향을 받으므로 경기 전에 테스트하세요.

League of Legends와 관련 이미지 및 명칭은 Riot Games의 자산입니다. 이 프로젝트는 Riot Games의 공식 제품이 아닙니다.
