# LOL Broadcast HUD

리그 오브 레전드 대회용 OBS 밴픽, 인게임 HUD 및 결과 화면입니다. 웹 밴픽, BO5 하드 피어리스와 RoFS를 지원합니다.

## 최신 버전: 0.2.0 (2026-11-11)

- 결과 화면 색상을 차콜·청회색으로 조정하고 블루·레드 승리 표시를 구분했습니다.
- 결과 화면의 대회 이름, 라운드/매치와 게임 번호가 컨트롤 페이지 설정을 따릅니다. 저장된 경기 통계와 팀 정보는 유지됩니다.
- 결과 화면의 KDA 글자 간격을 넓혔습니다.
- 컨트롤 페이지의 대회 로고를 인게임과 결과 화면에도 표시하고, 결과 화면의 팀 로고를 팀 이름에 맞게 갱신합니다.
- Cloudflare 도구가 없으면 외부 접속 시작 시 공식 다운로드 페이지와 설치 안내를 표시합니다.
- 인게임 HUD는 기존 색상을 유지합니다.

결과의 게임 번호를 바꾼 뒤에는 해당 경기의 통계를 다시 저장해야 결과 내용과 번호가 일치합니다.

## 주요 기능

- 40초 픽 교환 시간을 포함한 웹 밴픽과 OBS 관전 화면
- BO5 하드 피어리스: 이전 세트에서 픽한 챔피언을 제한하고 세트별 목록 표시
- RoFS: 운영자가 양 팀의 진영 및 선후픽 선택을 입력하며, 레드 선픽도 지원
- 인게임 점수판과 경기 결과 화면, 딜량·골드 그래프 이미지 인식

RoFS 선택과 세트 결과는 컨트롤 페이지에서 운영자가 입력합니다. 웹 밴픽은 롤 클라이언트에 픽을 자동 입력하지 않습니다.

## 실행

Windows 10/11 64비트와 Node.js 24가 필요합니다. 이 저장소에는 Node.js 실행 파일이 포함되지 않습니다.

```powershell
node server.js
```

실행 창을 유지하고 브라우저에서 `http://127.0.0.1:3197/control.html`을 여세요. OBS 브라우저 소스 주소는 `/draft.html`, `/ingame.html`, `/result.html`이며 1920×1080으로 설정합니다. 처음 챔피언 데이터를 불러올 때 인터넷 연결이 필요합니다.

외부 웹 밴픽을 사용하려면 컨트롤 화면에서 외부 접속 시작을 누르세요. 도구가 없으면 열리는 공식 다운로드 페이지에서 Windows 64비트 실행 파일을 받은 뒤, 이름을 `cloudflared.exe`로 바꾸고 `runtime/cloudflared.exe`에 넣습니다. 다시 외부 접속 시작을 누르면 연결할 수 있습니다. 팀 링크는 해당 팀에게만 전달하세요. 로컬 서버가 실행 중이어야 합니다.

`data/state.example.json`은 개인 경기 정보를 제거한 초기 설정입니다. 첫 실행 시 로컬 `data/state.json`이 생성되며 Git에서 제외됩니다. 실행 중 생성된 경기 정보와 팀 링크, 업로드 파일은 공개하지 마세요. 이미지 인식은 화면 배치와 해상도에 영향을 받으므로 경기 전에 테스트하세요.

League of Legends와 관련 이미지 및 명칭은 Riot Games의 자산입니다. 이 프로젝트는 Riot Games의 공식 제품이 아닙니다.
