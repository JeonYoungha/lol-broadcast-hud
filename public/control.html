방송컴 연결 · 내부 네트워크 HUD

관전컴과 방송컴을 같은 핫스팟이나 공유기에 연결하고 시작하세요. 주소는 방송컴 OBS 브라우저 소스에 입력합니다.

연결 상태 확인 중…

주소가 여러 개면 핫스팟에 연결된 IPv4 주소를 선택하세요. 접속이 안 되면 방화벽과 기기 간 통신 허용을 확인하세요. 컨트롤 패널은 관전컴에서 사용합니다.

방송컴 연결 · 외부 HUD (내부망 불가 시)

Cloudflare 임시 주소로 밴픽·인게임·결과 HUD만 공개합니다. 관전컴의 인터넷과 HUD 프로그램을 켜 두세요. 같은 주소를 아는 사람도 볼 수 있습니다.

연결 상태 확인 중…

주소는 다시 시작할 때 바뀔 수 있습니다. Cloudflare 연결 도구가 없으면 공식 다운로드 안내가 열립니다.
